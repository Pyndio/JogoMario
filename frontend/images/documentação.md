# Documentação do Jogo Mario

## 1. Sobre o Projeto

O Jogo Mario é um jogo 2D estilo plataforma desenvolvido como
trabalho prático para a faculdade.

O projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript,
com o objetivo de aplicar conhecimentos de desenvolvimento web,
trabalho em equipe e controle de versões utilizando Git e GitHub.

## 2. Objetivo do Projeto

O objetivo do projeto é desenvolver um jogo 2D de plataforma,
aplicando conceitos de desenvolvimento Front-End e organização
de um projeto de software.

O projeto também busca proporcionar a aplicação prática dos
conhecimentos adquiridos durante a disciplina.

## 3. Tecnologias Utilizadas

### HTML5

Utilizado para estruturar a tela do jogo e os elementos que
compõem o cenário.

### CSS3

Utilizado para a estilização visual do jogo e para a criação
de animações, incluindo a animação de entrada do personagem.

### JavaScript

Utilizado para implementar a lógica de funcionamento do jogo,
as animações e os comandos dos personagens e elementos da aplicação.

### Git e GitHub

Utilizados para o controle de versões, organização do projeto
e colaboração entre os integrantes da equipe.

## 4. Estrutura do Projeto

O projeto está organizado de acordo com a estrutura definida
para a atividade:

- `backend/` — diretório destinado aos recursos de backend.
- `docs/` — diretório destinado aos documentos e artefatos do projeto.
- `frontend/` — diretório que contém o projeto Front-End do jogo.
- `.gitignore` — arquivo utilizado para definir arquivos que não
  devem ser versionados.
- `LICENSE` — arquivo contendo a licença do projeto.
- `README.md` — arquivo com as informações principais do projeto.

## 5. Funcionamento do Jogo

O projeto consiste em um jogo 2D de plataforma inspirado no
universo do Mario.

A aplicação utiliza HTML5 para estruturar os elementos,
CSS3 para apresentar os elementos visualmente e realizar
animações, e JavaScript para controlar a lógica e os comandos
do jogo.

## 6. Desenvolvimento

O projeto encontra-se em constante evolução. Durante o
desenvolvimento, novas funcionalidades e melhorias podem ser
adicionadas de acordo com as necessidades do projeto.

## 7. Próximas Atualizações

Entre as possíveis atualizações do projeto estão:

- novos elementos visuais;
- ajustes nas mecânicas do jogo;
- novas funcionalidades;
- melhorias na experiência de interação com o jogo.
